# FEATURES.md

- **Banner Upload Studio**: Upload up to 3 banners (2:1 ratio) via developer panel; displayed on homepage carousel.
- **Campaign Slider**: Text‑based fallback carousel with customizable slides.
- **Donor Directory**: Search, filter, and manage donor profiles; includes sorting and status actions.
- **Data Reset**: Developer endpoint to clear all localStorage data for a fresh start.
- **Live Ticker**: Editable notice ticker displayed across pages.
- **Responsive Design**: Mobile‑first layout with glass‑morphism and dark‑mode support.
- **Authentication Mock**: Simple session handling for developer panel.

Future enhancements may include payment gateway integration, multi‑language support, and analytics dashboards.
